# Business Case — Medication Assistance Program Finder

## 1. Problem / Opportunity

Information about medication assistance programs can be spread across different manufacturer websites and resources, requiring healthcare staff to spend time locating programs and determining their requirements. A centralized resource could make it faster and easier to identify available assistance programs and the information needed to apply.

## 2. Proposed Solution

The Medication Assistance Program Finder would be a web application that
organizes information about medication assistance programs in one searchable location. Users could search or browse by medication and view available programs, eligibility requirements, required documentation, application instructions, and other relevant program information. Users could also bookmark frequently accessed programs for quick reference.

## 3. Options Considered

| Option | Description | Pros | Cons |
|--------|-------------|------|------|
| Option A | Continue locating assistance programs through individual manufacturer websites and other existing resources. | No additional development or maintenance costs; information comes directly from program sources. | Staff may need to search multiple websites and repeatedly locate the same information. |
| Option B (recommended) | Develop a centralized Medication Assistance Program Finder. | Provides one searchable location for commonly used program information; can reduce research time; frequently used programs can be bookmarked. | Requires development time and ongoing review to keep program information current. |

## 4. Feasibility

| Type | Assessment |
|------|------------|
| Operational — will people actually use/support this? | The application would support an existing medication assistance workflow by making commonly needed program information easier to locate. Staff could use the application as a reference while continuing to complete applications through the appropriate manufacturer or program. |
| Technical — can we build it with what we have/can get? | A functional prototype can be developed using a small set of simulated medication assistance program data. The application would primarily require collection, search, detail-view, and bookmark functionality and would not require integration with manufacturer systems. |
| Economic — does the payoff justify the cost? | The application would require development and ongoing maintenance, but it could reduce the amount of staff time spent searching for medication assistance program information. The value of the time saved could offset the cost of developing and maintaining the application. |
| Schedule — can it be done in a useful timeframe? | A prototype containing a limited number of medications and assistance programs can be completed within the project timeframe. Additional programs and features could be added later. |

## 5. Costs & Benefits

The following figures are estimates based on a hypothetical implementation and are used to evaluate the economic feasibility of the proposed system.

**Costs** (one-time + ongoing):

| Item | One-time | Ongoing/year |
|------|----------|----------------|
| Application development (40 hours at $30/hour) | $1,200 | — |
| Initial collection and organization of program information (20 hours at $25/hour) | $500 | — |
| Review and updating of program information (2 hours/month at $25/hour) | — | $600 |
| **Total** | **$1,700** | **$600/year** |

**Benefits** (tangible + intangible):

| Benefit | Tangible ($/time saved)? | Notes |
|---------|-----------------------------|-------|
| Reduced staff research time | $2,168/year | Assumes 20 searches per week with an average savings of 5 minutes per search at $25/hour. |
| Faster access to program information | Time saved | Searchable information reduces the need to navigate multiple resources. |
| Improved organization of information | Intangible | Program information is presented in a consistent format. |
| Improved information availability | Intangible | Staff have a centralized reference for frequently accessed assistance programs. |

**Payback period:** Approximately 1.1 years (about 13 months). Based on the estimated costs and benefits, cumulative benefits would equal cumulative development and operating costs after approximately 13 months.
**ROI:** Over five years, estimated total benefits are $10,840 and estimated total costs are $4,700. Using the formula (total benefits − total costs) / total costs, the estimated five-year ROI is 130.6%.

*(See Toolkit Part C — Financial Analysis Tools document for payback, ROI, and present value formulas.)*

## 6. Priority & Urgency

Healthcare staff who assist patients with medication access may regularly need to locate information about available assistance programs. Without a centralized reference, staff must continue searching separate resources for this information. Developing the application would provide a more efficient way to access commonly needed program information and create a resource that could be expanded as additional programs are identified.

## 7. Recommendation

Proceed with development of a prototype Medication Assistance Program Finder using a limited set of simulated medication assistance program data.
